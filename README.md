# 🎨 Artiva Studio

Artiva Studio is a creative and responsive website made to showcase artwork, creative ideas, and different art-related sections.

This project was built while learning web development and putting **HTML, CSS, and JavaScript** into practice.

## ✨ Features

* 📱 Responsive design
* 🎨 Hero section
* 🖌️ Features section
* 🖼️ Artwork gallery
* 🔍 Click on an artwork to view it larger
* 🌙 Dark and light mode
* 📱 Mobile navigation menu
* 💡 About section
* 📩 Separate contact page
* ✅ Basic contact form validation
* ✨ Scroll animations
* 🔗 Navigation links
* 📱 Social media icons

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
